# Longshore Pro Surf

A browser surf game in a single `index.html`, with no build step and no dependencies. Open the file in a browser, or serve the folder with any static host such as GitHub Pages.

You ride a peeling right-hander across a two-minute heat. Chain tricks into a combo before the whitewater catches you, then the five judges score your heat.

## Controls

| Keys | Action |
| --- | --- |
| Arrows / WASD | Steer where you point. In the air, left and right spin you. |
| Space | Pump for speed |
| Z · X · C | Grab: Indy, Stalefish, Method |
| Shift | Stall, to slow down into the barrel |
| P / Esc · M | Pause · sound |

On touch screens, drag on the left half of the screen to steer, and use the Pump and Grab buttons on the right.

## Tricks

- **Carves:** Bottom Turn, Top Turn, Snap, Off the Lip, Floater, Cutback and Roundhouse Cutback
- **Barrels:** Stay low inside the curl while the wave is hollow. Riding deep scores more.
- **Airs:** Hit the lip steep with the speed bar past the white mark. Spin 180 to 900 and add a grab. Land roughly straight or reversed. Airs play in slow motion to give you time to spin.

Tricks in the same combo multiply together, up to ×10. Repeating a trick is worth less each time. A wipeout loses the combo you haven't banked yet.

## Breaks

- **Golden Hour:** sunset point break
- **Coral Noon:** smaller tropical wave
- **Moon Tide:** bigger, faster and hollower, lit by bioluminescence

Your best score at each break is saved in the browser.
